# 🚨 Laboratorio de Troubleshooting de SRE: Caos en Producción

¡Atención equipo! El servidor principal de staging con **Ubuntu Server 24.04 LTS** ha sufrido una serie de fallas catastróficas encadenadas debido a una mala automatización de infraestructura. El despliegue de producción se encuentra detenido. Tu misión como SRE / Administrador de Sistemas es estabilizar el entorno y recuperar los accesos.

## 🛠️ Requisitos Previos
Antes de iniciar, asegúrate de tener instalado en tu máquina local:
* [VirtualBox](https://www.virtualbox.org/) (Versión reciente)
* [Vagrant](https://developer.hashicorp.com/vagrant/downloads) (Versión reciente)

## 🚀 Instrucciones de Inicio
1. Clona este repositorio en tu máquina local o descarga el archivo `Vagrantfile`.
2. Abre una terminal dentro de la carpeta donde se encuentra el archivo `Vagrantfile`.
3. Despliega el entorno ejecutando:
   ```bash
   vagrant up
   ```
